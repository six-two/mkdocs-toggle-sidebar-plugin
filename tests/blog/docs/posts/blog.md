## Input elements

If key bindings (`B`, `M`, `T`) are enabled, they should not trigger when you edit these elements:

- Text box: <input value="Some text">
- Text area: <textarea>Some multi-
line text</textarea>
- Dropdown menu: <select>
    <option>A</option>
    <option>B</option>
    <option>C</option>
</select>
- Editable divs and similar: <div contentEditable>some editable text</div>
